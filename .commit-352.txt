Il-Qawmien: its own relay, and the 17-map world (build 352)

SEPARATE RELAY, as asked: "different relay so it don't disturb the party
games". server/qawmien_relay.py is its own process, own port (8102 beside
8101), own database. It opens KARTI's accounts file in a mode where writing
is physically impossible and refuses to start if pointed at KARTI's db path,
so the party games cannot be disturbed by anything it does - crash, flood or
full disk. Its selftest proves KARTI's file is byte-identical after every
request, and no journal/WAL ever appears beside it.

ONE ACCOUNT, NO SECOND PASSWORD. KARTI hands the frame its live session token
by postMessage (never letting the frame read KARTI's localStorage: sync.js's
session keys are private layout, and the parent should decide in one place
what a frame is given). The relay validates that token against KARTI's own
session list, read-only.

OFFLINE IS UNAFFECTED. The phone's own save stays the local truth; the relay
only lets a character follow you to another phone. Divergent devices surface
the conflict rather than silently overwriting a character.

Also ships the new world: 17 maps, all 10x10, each framed whole with no
scrolling camera - the Dofus screen model. The field grid was re-cut from one
46x28 countryside with a one-tile overlap, so a seam cannot exist.

Gates: karti_server.py --selftest 326/326 (untouched, never restarted);
qawmien_relay.py --selftest 36/36; checkmaps 17 OK; checkatlas pass;
checkhover exit 0. Home, Story Mode and Multiplayer verified unaffected, and
the Il-Qawmien row is absent from the DOM entirely for non-admins.
